Act 1: Bad Test Patterns

The hidden time sinks

  • Delay Real async delays — Future.delayed(seconds: 3)
  • Setup Heavy setUp — setUp(() async { await Future.delayed(500ms) })
  • Parallelism Mega test files — 30+ tests in one file
  • Rendering Excessive pumping — 100x pump loops
  • I/O Real disk writes in tests

The Worst Offender

// Looks innocent... but waits 3 REAL seconds
test('should debounce search input', () async {
  cubit.search('query');
  await Future.delayed(const Duration(seconds: 3));
  expect(cubit.state, isA<SearchSuccess>());
});

The Fix: Workspace-Level Resolution

# .github/workflows/pr_check.yml
setup:
  steps:
    - run: dart pub get              # ONCE at root
    - uses: actions/cache@v4         # cache .dart_tool
      with:
        key: pub-${{ hashFiles('**/pubspec.lock') }}

analyze:
  steps:
    - run: dart analyze .            # ONCE for workspace

test:
  strategy:
    matrix:
      package: [app, core, payments, analytics]
  steps:
    # Restore cache — no pub get needed
    - if: needs.setup.outputs.affected
      run: flutter test

Key Takeaways

  • 1 Fix your tests first — async delays, heavy setUp, real I/O
  • 2 Parallelize across packages — simple shell script
  • 3 Bundle tests — reduce isolate cold start overhead
  • 4 Cache pub get at workspace level
  • 5 Analyze once at workspace root
  • 6 Test selectively using dependency graph
  • 7 Diff coverage — measure only what changed
